# FoodWise Project Statement

## Problem

Organizing a meal for a group of students can be a challenging task that requires taking into account a number of factors. With the number of students, the available budget, the stock of ingredients, and meal suitability, it can be overwhelming to plan the menu manually and make sure that no costs, resources, or students' dietary requirements are overlooked. FoodWise is a Java application that solves this problem by simplifying and automating the meal planning process and providing the best option based on the given criteria and available resources.

## Scope

The scope of the proposed solution includes the following features:

- Student management
- Ingredient management
- Meal management
- Ingredient availability check
- Meal filtering by budget
- Intelligent meal recommendation
- Calculation of meal total cost
- Remaining budget calculation
- Storage of meal plans
- Viewing stored meal plans
- Basic report generation

The current scope of the solution is focused on developing a console-based application in Java with a database as the primary source of data using JDBC and MySQL as relational database management systems. FoodWise is primarily intended to demonstrate Java features and concepts through the development of a working application that addresses a specific issue in the field of student welfare and meal planning.

## Target Users

The primary target user of the proposed solution is the administrator responsible for student meals. At that, the system can be applied in a variety of settings related to education or welfare and address the specific needs of small groups of students in terms of meal planning and budgeting.
